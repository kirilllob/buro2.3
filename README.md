# Получение игр

Проект позволяет получить список игр

## Установка
Скачайте необходимые файлы, затем используйте `рiр` (или `рiр3`‚ если есть конфликт с `Python2`) для установки зависимостей и установить зависимости. Зависимости можно установить командой, представленной ниже.

```
pip install -r requirements.txt
```

## Пример запуска
Для запуска скрипта у вас уже должен быть установлен `Python3`. Для запуска необходимо написать:
```
python main.py 
```


## Переменные окружения
Часть настроек проекта берётся из переменных окружения. Переменные окружения - это переменные, значения которых присваиваются программе `python` извне. Чтобы их определить, создайте файл `.env` c

`main.py` и запишите туда данные в таком формате: ПЕРЕМЕННАЯ = значение.

Пример содержания файла `.env`:
```
API_KEY = "api_key"
```
Получить токен API_KEY можно получить на [сайте](https://rawg.io/apidocs). Получите свой `api_key` и положите в переменную `API_KEY`
